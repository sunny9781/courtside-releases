# Courtside

**Mac** (Apple Silicon, M1 or newer)

**Easiest:** open **Terminal**, paste this line and press Return:

```
curl -fsSL https://raw.githubusercontent.com/sunny9781/courtside-releases/main/install.sh | bash
```

It downloads Courtside into your Applications folder and opens it, with no security warnings.

**Or download it yourself:** [Courtside.zip](https://github.com/sunny9781/courtside-releases/releases/latest/download/Courtside.zip). Unzip it and drag **Courtside** into **Applications**. When you open it, macOS will say it can't check the app. Click **Done**, then go to **System Settings › Privacy & Security**, click **Open Anyway** and enter your Mac password.

Either way, you only do this once. After that, Courtside updates itself. When a new version is ready, a **Restart to update** button appears at the top.

You'll need your own IPTV (Xtream Codes) login.
